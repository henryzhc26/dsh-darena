# dsh-darena · D宠大乐斗

**DSH 里的实时对战小游戏插件。** 侧栏点开就是一个占满高度的对局面板：跨用户实时匹配真人，双方各调自己 DSH 里配置的模型解同一张机关图，三局两胜定胜负。

- **主功能**：面板内直接打。匹配走公开对局服务 `https://hivisionelec.cn/dcdld`；三局两胜、11 档难度阶梯（7×7 到 29×29）、全球净胜榜。
- **练习模式**：对手固定免费档模型，双方都不消耗你的额度，打完不计榜。想先摸清规则就点它。
- **好友房**：六位房间码，跨设备开房，只有你俩。
- **附属功能**：把账号绑定的形象显示在客户端右下角（默认开；右键菜单或设置里可关，关掉不影响对战与战绩）。
- **形象唯一来源**：账号绑定的那个形象（`/api/identity` → `/api/pet-profile?uid=`）。已绑定就直接进大厅，不会重复问你要形象。
- 与 `dsh-ai-office`（AI 办公室）互不依赖，可各自单独安装、单独卸载。

## 安装

```bash
dsh plugin add https://github.com/henryzhc26/dsh-darena/releases/download/v0.1.12/dsh-darena-0.1.9.tgz
```

或用仓库直接装：

```bash
dsh plugin add github:henryzhc26/dsh-darena
```

装完重启 DSH，侧栏出现「D宠大乐斗」。

本机开发用：

```bash
npm run check && npm run install:local   # 装到 ~/.dsh/plugins/dsh-darena/
```

## 玩法

1. 进面板 → 已绑定形象直接进大厅（未绑定先选一个形象）。
2. 点「开始匹配」，等另一位玩家。
3. 每局开打前可以换这局用的模型与思考强度；不想花 token 就留在免费档。
4. 三局两胜：一方先到 2 分结束。单局判定依次比「是否到达终点 → 剩余步数 → 用时」。
5. 结算与排行榜显示双方用过哪些模型、各自的场次与净胜。

## 它凭什么不一样

- 不是随机数对撞，也不是预设题库：**真的调用你 DSH 里已接入的模型**，用模拟器判分，不看模型自己说对不对。
- 每局只调两次模型（双方各一次），token 消耗小，玩起来十几秒一局。
- 跨用户排行榜按净胜场次排，不是本地假数据。

## 隐私与凭据

插件不读取、不存储你的任何 API key；比赛走公开对局服务，模型调用在你的本机完成。桌面挂件只读取本机 8917 服务的形象资源。
